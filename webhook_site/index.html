Endpoint

Untuk berbagai layanan yang mengirim JSON:

POST/api/webhook

Untuk event Telekos dengan validasi tanda tangan:

POST/api/telekos

Endpoint umum memakai Authorization: Bearer WEBHOOK_API_KEY. Telekos memakai signature resminya.

curl -X POST https://domain-anda/api/webhook \
  -H 'Authorization: Bearer KUNCI_ANDA' \
  -H 'Content-Type: application/json' \
  -d '{"source":"my-api","message":"Webhook berhasil"}'

Konfigurasi Vercel

Tambahkan environment variables di Project → Settings → Environment Variables, lalu redeploy.

TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
WEBHOOK_API_KEY
TELEKOS_WEBHOOK_SECRET

Secret hanya dibaca fungsi server. Health check tidak menampilkan nilainya.
